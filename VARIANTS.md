# GitHub Profile README Variants (`vishalkdotcom/vishalkdotcom`)

Five visual-art + engineering-telemetry profile editions live in `variants/` with custom CSS-animated SVG artwork in `assets/`:

1. **`variants/01-synth-telemetry-rack.md`** *(Active Default in `README.md`)* — **The Modular Synthesizer & Oscilloscope Rack** (`assets/01-synth-telemetry-rack.svg`): 3-module Eurorack synthesizer chassis with glowing phosphor CRT dual-trace oscilloscope (`54.90` vs `54.31` wave drift), rotary attenuverter knobs (`2.08x`, `6 GATE`, `6 OKRs`), sequencer launchpad, and draped patch cables.
2. **`variants/02-constellation-observatory.md`** — **The Constellation of Proof Star Map** (`assets/02-constellation-observatory.svg`): Deep-space astronomical observatory chart mapping 4 sectors of work around a central identity sun with pulsing star rings.
3. **`variants/03-silicon-wafer-die.md`** — **The Custom Silicon Die & PCB Interconnect** (`assets/03-silicon-wafer-die.svg`): Emerald solder-mask PCB with gold BGA pads, animated packet traces, and a 4-quadrant exposed silicon die connected to 4 peripheral work cores.
4. **`variants/04-arcade-proof-cabinet.md`** — **The 1986 Arcade Boss-Rush Cabinet** (`assets/04-arcade-proof-cabinet.svg`): Retro CRT arcade attract-mode screen framing 4 real production engineering battles as cleared Boss Stages with HP bars and playable cartridges.
5. **`variants/05-kinetic-brutalist-poster.md`** — **The Swiss Kinetic Brutalist Poster** (`assets/05-kinetic-brutalist-poster.svg`): High-contrast architectural typography poster with monumental proof numbers (`54.90 != 54.31`, `2.08×`, `164 vs 350 KiB`, `6 BUGS`) and automatic dark/light theme adaptation.

## Switching the Active Profile

Copy any variant into `README.md` and push:

```bash
cp variants/01-synth-telemetry-rack.md README.md     # Default: Modular Synth & CRT Rack
cp variants/02-constellation-observatory.md README.md # Deep-Space Constellation Star Map
cp variants/03-silicon-wafer-die.md README.md        # Custom Silicon Die & PCB Traces
cp variants/04-arcade-proof-cabinet.md README.md     # 1986 Arcade Boss-Rush Scoreboard
cp variants/05-kinetic-brutalist-poster.md README.md # Swiss Kinetic Brutalist Poster
```
